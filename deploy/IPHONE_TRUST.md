# Getting the camera to work on iPhone

iOS blocks `getUserMedia` (the camera) unless the page is served over **HTTPS**
(or is `localhost`). Since your phone hits MacroLog through a network hostname,
you need HTTPS that Safari trusts. Pick whichever matches how your Caddy issues
certs.

---

## If Caddy uses real ACME certs (Let's Encrypt / DNS-01) — easiest
Nothing special. The cert is already trusted by iOS. Just:

1. Browse to `https://your-macrolog-host/` on the phone.
2. Tap the green camera button → Safari prompts **"MacroLog would like to use
   the Camera"** → Allow.
3. Done. Optionally Share → **Add to Home Screen** for a full-screen app.

No certificate steps needed. This is the path of least resistance — use it if
your host has public DNS + working ACME.

---

## If Caddy uses its internal/local CA (`tls internal`)
Safari won't trust Caddy's private root until you install it once per device.

### 1. Find Caddy's root CA on the machine running Caddy
```
# Linux service user 'caddy':
/var/lib/caddy/.local/share/caddy/pki/authorities/local/root.crt
# macOS (Caddy app / caddy run as your user):
~/Library/Application Support/Caddy/pki/authorities/local/root.crt
# Generic fallback:
ls ~/.local/share/caddy/pki/authorities/*/root.crt
```

### 2. Get `root.crt` onto the iPhone
Any of: AirDrop from a Mac, email it to yourself and open the attachment, host
it at `https://yourhost/root.crt`, or Files.app → save.

### 3. Install the profile
- Tapping the `.crt` → iOS says "This certificate can be installed" →
  **Settings > Profile Downloaded > Install**.

### 4. TRUST IT (the step everyone misses)
Installing ≠ trusting. Go to:
```
Settings > General > About > Certificate Trust Settings
```
Toggle **Enable** next to the Caddy root. Now Safari treats every cert chained
to it (including `https://macrolog.home`) as valid and the camera prompt works.

### 5. Verify
Open `https://your-macrolog-host/` — no warning banner, lock icon shows the
Caddy issuer. Camera button should now behave like the ACME case above.

> Certs generated by `deploy/make-cert.sh` are trusted the same way: install
> `macrolog.crt` itself as a profile and enable it in Certificate Trust
> Settings. But since you have Caddy, prefer letting Caddy own TLS.

## Troubleshooting
- **Camera button does nothing / no prompt:** not HTTPS, or cert untrusted
  (redo step 4). Check the address bar shows a padlock with no warnings.
- **"NotAllowedError":** you denied the prompt earlier — tap the `AA` / share
  icon in Safari's address bar → Website Settings → Camera → Allow.
- **Works on Wi-Fi LAN but not away:** Netbird isn't up on the phone, or the
  LXC binds only loopback and Caddy is elsewhere (see Option B in
  `Caddyfile.snippet`).
- **Stale PWA after updates:** the service worker caches the shell. Hard-refresh
  once, or remove & re-add from Home Screen.
