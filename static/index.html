Set up Apple Health

    
The app prepares the data; an iOS Shortcut writes it to
      Health. One Shortcut handles both today and any missed days.

    
    
      
  1. In the Apple Health card, tap Generate token and copy it.
        It is shown only once.
    2. 
      
  2. Open Shortcuts → + → Get Contents of URL.
        URL: /health/pending;
        method GET; header Authorization =
        Bearer <token>.
    3. 
      
  3. Repeat with Each item in pending:
        Log Health Sample for Dietary Energy (kcal), Protein (g),
        Carbohydrates (g), Total Fat (g), and Fiber (g). Set each sample's
        date to item.sample_at so backfilled days land on the
        right day. Optional: weight.kg → Body Mass and
        body_fat_pct → Body Fat Percentage.
    4. 
      
  4. After logging each day, Get Contents of URL with URL
        /health/ack, method
        POST, same auth header, JSON body
        {"dates": [item.date]}.
    5. 
      
  5. Run it manually, or add a daily Personal Automation. Confirmed days
        are skipped automatically.
    6. 
    

    
The app can't see whether HealthKit actually saved a sample;
      a day is confirmed only after the Shortcut posts to
      /health/ack. If it logs but fails before confirming, the next
      run may duplicate it.
